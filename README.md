# Prakarsh Gupta | Personal Portfolio

This repository contains the source code for the personal portfolio website of **Prakarsh Gupta** (AI Systems Engineer & Software Engineer at Expedia Group).

## About The Project

A sleek, responsive, and modern developer portfolio website designed with anti-slop principles:
- **Framework:** Next.js (App Router, Turbopack)
- **Styling:** Tailwind CSS
- **Typography & Icons:** Phosphor Icons (`@phosphor-icons/react`)
- **Sections:** Hero, About, Work Experience, Featured Projects & Talks, Technical Skills, Education, and Contact.

## Running Locally

To run this website locally on your computer:

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Building for Production

```bash
npm run build
npm run start
```
